One sentence (224 characters) that would convince a friend who has never coded
to let an AI agent build their first app idea on [make.fun](https://make.fun).

## Entry

> Tell make.fun's AI agent your app idea in plain words — no coding, no jargon — and it will turn it into a real working app you can tap, use and share today, so the idea you've carried for years finally gets its first chance.

## How it works

`main.py` (Python standard library only, no network, no randomness) writes
the sentence above to `/output/entry.txt`. Two runs produce byte-identical
output (sha256 `a03cac71d50b67f93e01a7b3f75926b381b35459f24235cab01dfe3454910916`).

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
